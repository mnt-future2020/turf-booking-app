# Setup Git & GitHub

## Initialize Git Repository

```bash
git init
git add .
git commit -m "Initial commit: TurfBooking SAAS Application"
```

## Push to GitHub

1. Create new repository on GitHub
2. Run these commands:

```bash
git remote add origin https://github.com/YOUR_USERNAME/turf-booking-app.git
git branch -M main
git push -u origin main
```

## Clone Later

```bash
git clone https://github.com/YOUR_USERNAME/turf-booking-app.git
cd turf-booking-app
npm install
```
